# Stock Market Analysis — Apple, Microsoft, Netflix & Google

This project analyzes the stock market performance of Apple, Microsoft, Netflix,
and Google over a three-month period (Feb–May 2023).

## Objectives
- Compare stock price trends across companies
- Analyze moving averages and return patterns
- Measure and compare volatility
- Perform correlation analysis between stock prices

## Key Analysis
- Adjusted close price trend comparison
- 7-day moving average analysis
- Daily return and rolling volatility analysis
- KPI comparison across companies
- Stock price correlation matrix

## Tools Used
- Microsoft Excel

## Key Insights
- Apple and Microsoft show strong correlation, indicating similar market behavior.
- Netflix exhibits higher volatility and stronger price movements.
- Google shows moderate alignment with Apple and Microsoft.
